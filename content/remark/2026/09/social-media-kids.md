今回の記事は，八田真行さんの以下の記事を起点にしよう。

- [オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界（八田真行） - エキスパート - Yahoo!ニュース](https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2)

特定のサイトやサービスに対して年齢制限を課す政治要求は昔から根強いが，上手くいったという話は聞いたことがない。
そもそも「子どものため」に SNS に年齢制限を課すという言い分は本当に妥当なのだろうか。
みんな「子どものため」というお題目のせいで思考停止しているのではないのか？

{{< fig-quote type="markdown" title="オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界" link="https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2" >}}
社会心理学者ジョナサン・ハイトの[『不安の世代――スマホ・SNSが子どもと若者の心を蝕む理由』](https://www.soshisha.com/book_search/detail/1_2819.html)（原題 The Anxious Generation、2024年。邦訳は2026年、草思社）は、スマートフォンとSNSが子どもの心をむしばんでいると訴えて、世界的なベストセラーとなった。
{{< /fig-quote >}}

この『不安の世代（The Anxious Generation）』は [yomoyomo さんのブログ記事](https://yamdas.hatenablog.com/ "YAMDAS現更新履歴")にも時々登場するので（読んではいないが）名前は知っていたけど，よくあるニセ科学（pseudo-science）の類だろうとスルーしていた。
だって展開が「水からの伝言」や「ゲーム脳」と同じなんだもん。

ところが海外ではそうでもないらしい。

{{< fig-quote type="markdown" title="つながりのテクノロジーはまたしても我々を引き裂く – WirelessWire & Schrödinger's" link="https://wirelesswire.jp/2025/05/88642/" >}}
若年層のソーシャルメディア（やスマートフォン）の利用規制を動かしたのは、昨年欧米で大ベストセラーとなったジョナサン・ハイトの（なぜ未だ邦訳が出ないのか理解できない）『[The Anxious Generation: How the Great Rewiring of Childhood Is Causing an Epidemic of Mental Illness](https://www.penguinrandomhouse.com/books/729231/the-anxious-generation-by-jonathan-haidt/)』、そして今年Netflixで配信が開始されるや[世界71カ国でストリーミング1位となったドラマ『アドレセンス』の影響](https://dot.asahi.com/articles/-/253903)が大きいでしょう。

『The Anxious Generation』については[正反対の議論もメディアに登場](https://wired.jp/article/pete-etchells-jonathan-haidt-smartphones/)しましたし、それに対して著者の[ハイト自身も反論しています](https://gigazine.net/news/20240412-social-media-cause-teenage-mental-illness/)が、『アドレセンス』ともども、思春期の子を持つ親世代を[突き動かす](https://jp.reuters.com/economy/industry/TNAMRLMASVN4BEYPMS7TRIMQEY-2024-12-02/)だけのインパクトがありました。
{{< /fig-quote >}}

（邦訳版『不安の世代』は WirelessWire のブログ記事が出た後に[刊行](https://yamdas.hatenablog.com/entry/20251218/anxious-generation "ジョナサン・ハイト『不安の世代：スマホ・SNSが子どもと若者の心を蝕む理由』が（ようやく）来月出る - YAMDAS現更新履歴")された）

うわぁ。
トンデモがカルトに発展する典型的なパターンだよ。
ぶっちゃけ「不安の世代」とは子どもではなく（トンデモに踊らされる）今の大人世代なんじゃないのか？

しかも政治家や為政者が（おそらく票集めのために）これに便乗するという最悪のケース。
カルトや哲学との癒着による動員は政治家の最も得意とするところだからね。
ナチスドイツ時代のヒトラーもやってたし。

八田真行さんは SNS を巡る危険や脅威についての議論を2つに分けるべきだと主張する。

{{< fig-quote type="markdown" title="オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界" link="https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2" >}}
一つは、SNSを使うこと自体が子どもの心の健康をむしばむ、という主張である。これを支える科学的な根拠は、一般に思われているほど強くない。英国の研究者エイミー・オーベンとアンドリュー・プシビルスキが、[英米の三つの大規模調査、計約35万人分のデータを分析した研究](https://www.nature.com/articles/s41562-018-0506-1)がある。それによれば、デジタル技術の利用と若者の幸福感の間には確かに負の関連が見られたが、その大きさはごくわずかで、幸福感の個人差のうち説明できるのは最大でも0.4％にすぎなかった。[研究チームによれば](https://www.oii.ox.ac.uk/technology-use-explains-at-most-0-4-of-adolescent-wellbeing/)、これはジャガイモを日常的に食べることと幸福感との関連とほぼ同じ程度である。著者らは、この程度の効果は政策を変える根拠にするには小さすぎると結論づけている。
{{< /fig-quote >}}

デジタル技術の利用によるインパクトはじゃがいも程度らしい（笑）

{{< fig-quote type="markdown" title="オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界" link="https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2" >}}
もう一つは、いじめや誹謗中傷、性的な目的で子どもに近づくグルーミング、性的な画像を送らせて脅すセクストーション、闇バイトへの勧誘といった、具体的な被害である。こちらは現実に起きており、真剣に対処しなければならない。本稿は、こうした危険を軽く見るものではない。

しかし問題は、一律の年齢制限という大ざっぱな対策では、これらの具体的な被害を防げないことである。被害の多くは、見知らぬ大人から届くメッセージ、興味を過激な方向へと引きずり込むおすすめ機能、居場所の共有といった、特定の機能と特定の加害者を通じて生じる。グルーミングは、禁止対象から外れたメッセージアプリやオンラインゲームでも起こる。
{{< /fig-quote >}}

要するに「子どもの心の健康をむしばむ」悪い大人やサービスのダークパターンは野放しで，被害を受ける子ども側をパージするという本末転倒なことをやっている（やろうとしている）わけだ。
現代においても子どもは人間社会におけるマイノリティで，公衆空間の周辺（もしくは外側）に置かれる（置かれようとする）存在なのである。

その結果どうなったか。
記事ではオーストラリアの事例を紹介している。

{{< fig-quote type="markdown" title="オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界" link="https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2" >}}
規制当局であるeSafetyコミッショナーが[2026年3月に公表した報告](https://www.esafety.gov.au/sites/default/files/2026-03/SocialMediaMinimumAgeComplianceUpdateMarch2026.pdf)は、まったく異なる現実を示している。8〜15歳の子を持つ保護者898人への調査では、SNSアカウントを持つ子の割合は、施行前の約5割から約3割に減った。ところが、施行前にアカウントを持っていた子のうち、Facebook、Instagram、Snapchat、TikTokでは約7割、YouTubeでも約半数が、施行後もそのままアカウントを持ち続けていた。最も多かった理由は、「プラットフォームからまだ年齢確認を求められていない」という拍子抜けするものだった。

同じ報告書は、プラットフォーム側の不適切な運用も指摘している。16歳未満と申告していた利用者にわざわざ年齢確認を受けるよう促したり、16歳以上という判定が出るまで同じ確認を何度でもやり直せるようにしたりしていたサービスがあったというのである。
{{< /fig-quote >}}

（今は知らないが）大昔のアダルトサイトの年齢確認では「未成年」を選択するとキッズ向けサイトにリダイレクトするという牧歌的な仕組みだった。
いずれにせよ，バカ正直に申告して期待する結果を得られないのなら迂回するに決まっている。
「[インターネットは検閲をダメージであると解釈し，それを回避する]({{< ref "/remark/2016/11/the-shadow-web.md" >}} "“The Shadow Web” （再掲載）")」というやつだ。

{{< fig-quote type="markdown" title="オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界" link="https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2" >}}
規制の線引きにも不整合がある。いじめやグルーミングが起こりうるメッセージアプリのWhatsAppやMessenger、チャットサービスのDiscord、オンラインゲームのRobloxなどは、[規制対象から外れた](https://www.esafety.gov.au/about-us/industry-regulation/social-media-age-restrictions/faqs)。[オーストラリア人権委員会](https://humanrights.gov.au/about/news/proposed-social-media-ban-under-16s-australia)は、この法律が子どもや若者の権利を大きく損なうおそれがあるとして重大な懸念を示し、一律の禁止は正しい対応ではないと述べていた。
{{< /fig-quote >}}

これだけ見ても「子どものため」という旗を掲げる連中は，実は子どものことなど1ミリも考えてないということが分かるだろう。

{{< fig-quote type="markdown" title="オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界" link="https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2" >}}
一律の禁止は、弱い立場にある子どもたちに、とりわけ重くのしかかる。性的少数者の若者や移民の子どもなど、家庭や地域で孤立しがちな子どもたちにとって、SNSは支援や仲間につながる重要な手段である。
[...]
日本のこども家庭庁の有識者会議でも、[「SNSが子どもの居場所になっている」「子どもの表現の自由や知る権利を損なう」といった慎重論](https://kumanichi.com/articles/2019727)が出ていた。
{{< /fig-quote >}}

八田真行さんの記事の主題である「技術的・法的・社会的限界」については，記事のほうを参照していただきたい（全部書くと元記事の丸写しになるのでw）。
記事では欧州や日本の状況も紹介されている。

個人的に気になっているのは「年齢確認」をサービスに組み込むことでセキュリティ・リスクを呼び込む点である。

{{< fig-quote type="markdown" title="オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界" link="https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2" >}}
厄介なのは、回避の手段そのものが新たな危険を生むことである。[無料のVPNの多くは基本的なセキュリティ対策を欠き、利用者のデータを集める業者の仲介役になっている](https://www.govinfosecurity.com/vpn-use-surges-as-uk-online-safety-act-takes-effect-a-29076)と、セキュリティの専門家は警告している。結果として、ルールを守る真面目な子どもだけが締め出され、抜け道を知る子どもほど、より危険な道具を使って、大人の目の届かない場所へと移っていく。本末転倒である。
{{< /fig-quote >}}

{{< fig-quote type="markdown" title="オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界" link="https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2" >}}
身分証の画像や顔写真、クレジットカード情報を集めた年齢認証のデータベースは、サイバー犯罪者にとって格好の標的である。その規模は小さくない。
[...]
日本で同じことが起きれば、数千万人規模のデータベースが生まれることになる。成人向けサイトの年齢確認とひも付いて、政治家や著名人、スポーツ選手の閲覧履歴が記録されていれば、ゴシップ雑誌なら高値で買い取るだろうし、恐喝や政治的圧力の材料にもなる。小規模な年齢確認事業者が、世界中のハッカーの攻撃や、内部関係者による持ち出しに耐えられるだけの備えを持てるとは考えにくい。
{{< /fig-quote >}}

{{< fig-quote type="markdown" title="オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界" link="https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2" >}}
ネットの安全の基本は、「見知らぬサイトに身分証やクレジットカードの情報を安易に入力しない」ことである。ところが、政府が年齢確認を義務付ければ、国民はあらゆるサイトで個人情報を差し出すことに慣れてしまう。マフェットは2016年の時点で、年齢確認の義務化が[英国民の4割近くに、見知らぬサイトに電話番号やクレジットカード番号を入力したり、SNSのデータを差し出したりする悪い習慣を植え付ける](https://medium.com/@alecmuffett/a-sequence-of-spankingly-bad-ideas-483cecf4ba89)と警告していた。その懸念は現実になりつつある。
{{< /fig-quote >}}

ではどうすればいいのか。
八田真行さんは「国家が子どもを一律にネットから締め出すのではなく」「プラットフォームに「安全な設計」を義務付ける」「端末（OS）で、必要最小限の年齢情報だけを扱う」「家庭・学校・行政がそれぞれの役割を果たす」と提言されている。

{{< fig-quote type="markdown" title="オンライン年齢認証とSNS年齢制限の技術的・法的・社会的限界" link="https://news.yahoo.co.jp/expert/articles/cf4dc975624f9a2b29752d9bf154e25ae30739d2" >}}
セキュリティ専門家マーカス・ラナムが主張した「[ラナムの法則](https://www.usenix.org/system/files/login/articles/1430-ranum.pdf)」というものがある。「**社会問題はソフトウェアでは解決できない**」という原則だ。使える技術手段が目標に合っているかを率直に検討し、合っていないなら、目標そのものを考え直すべきだという戒めである。
{{< /fig-quote >}}

人間社会の問題，特に人間関係の問題であれば，それを解決できるのは人間だけである。
そのための建付けとしてソフトウェア技術を用いるのであれば（ソフトウェアエンジニアの端くれとして）歓迎すべきことだが，それ自体が問題を解決するわけではないという点は頭に入れておくべきだろう。
