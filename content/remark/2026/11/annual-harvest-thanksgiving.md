## 新嘗祭と勤労感謝の日

念のために触れておくと，元々の新嘗祭は旧暦十一月の2回目の卯の日に行われていた（後述するが，出雲では同等の神事が旧暦十月に行われる）。
明治時代に入り，明治の改暦（明治6年〜）を機に11月23日に固定された経緯があった。

{{< fig-quote type="markdown" title="暦Wiki/歴史/明治以降の休日 - 国立天文台暦計算室" link="https://eco.mtk.nao.ac.jp/koyomi/wiki/CEF2BBCB2FCCC0BCA3B0CAB9DFA4CEB5D9C6FC.html" >}}
- 明治12年07月05日 第27号布告 神甞祭を10月17日に改定 ([国立国会図書館](https://dl.ndl.go.jp/info:ndljp/pid/787959/59))
  - {{% ruby "かんなめ" %}}神甞{{% /ruby %}}祭、{{% ruby "にいなめ" %}}新嘗{{% /ruby %}}祭はともに収穫祭の意味合いを持つ祭日ですが、前者は伊勢神宮の、後者は天皇家の祭日です。
  - 神甞祭は、[明治6年暦](https://library.nao.ac.jp/kichou/archive/9052/M6/kmview.html)では11月6日＝天保暦で九月十七日となっていますが、明治06年07月20日 第258号布告にて[太陽暦](https://eco.mtk.nao.ac.jp/koyomi/wiki/C2C0CDDBCEF1.html)の9月17日に改定 ([国立国会図書館](https://dl.ndl.go.jp/info:ndljp/pid/994174/145))、以後 9月17日とされていました。
  - [太陰太陽暦](https://eco.mtk.nao.ac.jp/koyomi/wiki/C2C0B1A2C2C0CDDBCEF1.html)の日付と[太陽暦](https://eco.mtk.nao.ac.jp/koyomi/wiki/C2C0CDDBCEF1.html)の日付には[1か月ほどのズレ](https://eco.mtk.nao.ac.jp/koyomi/wiki/C2C0B1A2C2C0CDDBCEF12FC3D6B1BCCBA1.html#a4c4217c)がありますから、月遅れの日取りに変更したわけです。
  - 新嘗祭も本来は[太陰太陽暦](https://eco.mtk.nao.ac.jp/koyomi/wiki/C2C0B1A2C2C0CDDBCEF1.html)十一月2回目の[卯](https://eco.mtk.nao.ac.jp/koyomi/wiki/BDBDC6F3BBD9.html)の日ですが、明治6年の該当する日は翌7年1月10日になるため、[明治6年暦](https://library.nao.ac.jp/kichou/archive/9052/M6/kmview.html)には記載されていません。
  - こちらは明治06年07月20日 第258号布告にて[太陽暦](https://eco.mtk.nao.ac.jp/koyomi/wiki/C2C0CDDBCEF1.html)11月2回目の[卯](https://eco.mtk.nao.ac.jp/koyomi/wiki/BDBDC6F3BBD9.html)の日＝明治6年11月23日を採用、以後11月23日に固定されました。
{{< /fig-quote >}}

この新嘗祭の祭日が戦後に勤労感謝の日に当てられた。

{{< fig-quote type="markdown" title="各「国民の祝日」について - 内閣府" link="https://www8.cao.go.jp/chosei/shukujitsu/gaiyou/kaku.html" >}}
祝日法の制定前、１１月２３日は祭日の「新嘗祭」として休日とされており、国民の生活の中でも、新穀に感謝する日でした。同法の制定に当たっても、当初、この日を「新穀祭」や「新穀感謝の日」 とする提案もありました。勤労感謝の日は、いにしえからの収穫感謝の風習を生かしつつ、感謝の日として新たに設けられたといえます。

当時の報告書 １では、この日の「感謝」について、「国民が毎日生活を続けていられるのは、お互いがお互いを助け合っているからである。従って、ここにいう感謝というのは、すべての人がすべての生産とすべての働きとに感謝し合うのでなければならない。この感謝の心もちは、今日のような世相のけわしい時には最も必要なものであるが、世の中が落ち着いた時にも常に大切なものである」と説明されています。
{{< /fig-quote >}}

## 佐太神社の神在祭

「そういや，[昨年の今頃]({{< ref "/remark/2025/11/autumn-leaves-at-matsue-catle.md" >}} "松江城で紅葉狩り（お散歩カメラ 2025-11-22）")に[佐太神社]でお祭りやってたな」と思い出し，行ってみることにした。

{{< fig-img src="./55668812500_f5b1df0cc5_e.jpg" title="佐太神社（神在祭） | Flickr" link="https://www.flickr.com/photos/spiegel/55668812500/" >}}

おー。
やってるやってる。

佐太神社のこのお祭りは「{{% ruby "じんざい" %}}神在{{% /ruby %}}祭」というらしい。

{{< fig-quote type="markdown" title="神在祭 佐太神社公式ホームページ" link="https://sadajinjya.jp/?m=wp&WID=4196" >}}
一般に陰暦10月を神無月（かんなづき）と云いますが出雲國では神在月（かみありづき）と申します。古来諸説、俗説多くありますが、神在はジンザイと読み、鎮齋（ちんさい）すなわち「忌（いみ）」の意味で新嘗祭（にいなめさい）に関係を持っていると思われます。新嘗には斎戒を厳重に行う風俗があり、新穀を神に献ずる祭を相新嘗（あいにいなめ）といって10月に行っていました。大宝律令が制定されると伊勢神宮だけは尊崇のため祭を繰り上げて9月に行い、その他は繰り下げて11月に行った為10月は祭りが少ない月、すなわち「神無月」となったのです。しかし、出雲國では依然として10月に新穀を献ずる新嘗の祭が行われ、また、風土記に載る意宇（おう）、秋鹿（あいか）、楯縫（たてぬい）、出雲の神名火・神名樋山（かんなびやま）に神々が去来するというカンナビ信仰が結びつき出雲國特有の祭として残ったと考えられています。中世になるとに諸国の神々は出雲國お集まりになるという伝承が生まれ、出雲國では「神在月」と云うようになりました。

[...]

厳重な物忌みの祭であった為、時代が下ると間に中根（なかね）と呼ぶ緩和日を3日間設け、斎戒を解いたのでした。この当時佐陀大社は八百万（やおよろず）の神々の母神である伊弉冉尊の大元の社で、その背後の山に陵墓を祀っていると伝えていました。陰暦十月は伊弉冉尊（いざなみのみこと）が神去りました月であるという卜部（うらべ）家又は陰陽道の説により、八百万の神々は毎年この月になると当社にお集まりになり母神を偲ばれるのだとされ、この祭りを「お忌祭」と呼び、中根を中陰の意味としました。そして明治30年頃より陰暦10月を陽暦11月に改め上忌が無くなり下忌のみを執行することになり現在にいたっています。
{{< /fig-quote >}}

あれ？ 「神迎え」って出雲大社の神事じゃないの？

### 神様を迎えるのは出雲大社だけじゃない

「神在祭」は出雲大社のそれが有名だが，実は出雲大社（杵築神社）だけではなく，出雲各地で行われているらしい。

{{< fig-quote type="markdown" title="１ 神在祭はどの神社で行われるのですか｜島根県立古代出雲歴史博物館" link="https://www.izm.ed.jp/cms/cms.php?id=281&mode=v" >}}
縁結びなど様々な事柄の縁を結ぶということなどから出雲大社の神在祭が有名ですが、松江市の佐太神社や神魂神社（本殿は国宝です）、熊野大社、出雲市の万九千神社など、現在では10社で神在祭が行われています。

神々が出雲に集うことは12世紀半ばの『奥義抄』にすでに記され、また14世紀の『詞林采葉抄』には、「出雲では10月が神在月と呼ばれ、神在社と呼ばれる佐太神社に神々が集う」と記されています。また、また神社側に伝わる資料を見ると、例えば出雲大社では１４世紀半ば、佐太神社では１５世紀末の資料に「神在祭」に関連する記載が見られます。このように、中世末には多くの神社で神在祭が行われるようになったと考えられます。
{{< /fig-quote >}}

このうち神迎え神事を行っている神社として，出雲大社と佐太神社以外では，松江市の[熊野大社](http://www.kumanotaisha.or.jp/kamiari.html "http://www.kumanotaisha.or.jp/kamiari.html")や出雲市の[朝山神社](https://izumo-kankou.gr.jp/6404 "神在月｜出雲観光ガイド【出雲観光協会公式ホームページ】")が知られている[^k1]。

[^k1]: [熊野大社]では2013年（平成25年）に神迎えを含む神在祭を復活させた。毎年旧暦十月十日に神迎祭，翌十一日に神在祭が行われ、二十六日に神等去出祭が行われる。また新嘗祭に相当する新穀感謝祭を現行暦12月2日に行っている。新嘗祭自体は天皇家の神事だからね。

{{< fig-quote type="markdown" title="神在月｜出雲観光ガイド【出雲観光協会公式ホームページ】" link="https://izumo-kankou.gr.jp/6404" >}}
神々が集う出雲の各神社では「神迎祭(かみむかえさい)」に始まり、「神在祭（かみありさい）」そして、全国に神々をお見送りする「神等去出祭(からさでさい)」が行われます。
{{< /fig-quote >}}

神迎祭から神等去出祭までの一連の祭事は旧暦十月に行われることが多いが，どうも佐太神社は旧暦ではなく，月遅れの現行暦11月に（つまり戦前の新嘗祭の祭日に合わせて）行っている，ということのようだ。
しかも庶民の「お祭り」に絡めているのが面白い。
出雲市内の各神社は出雲大社に歩調を合わせてるんだろうな。

いや，神様が来たり行ったりするアレってぶっちゃけ百鬼夜行なのよ。
神と鬼はコインの裏表だからね。
私は子供の頃に親から「神様が渡ってるところを見たら連れ去られる（から早く寝ろ）」と脅されて，しばらく夜中のトイレに行けなかったよ。
いたいけな子供になに言うねん！

まぁ，祭事に信仰する神様を迎えるのは普通のことだし，中央に対する出雲の立場[^r1] や神事の変遷なども併せて，いつの間にか「全国の神様が集まる」とか大風呂敷を広げるようになったと邪推&憶測するのだが，どうだろう。

[^r1]: 古代出雲地方は「神郡」と呼ばれていた。神郡とは簡単に言うと宗教特区である。なので中央の決まりに縛られず独自の祭祀や風習を行うことができたと思われる（[参考]({{< ref "http://localhost:1313/remark/2023/09/ruins-in-ou-plain-1.md" >}} "八雲立つ風土記の丘 遺跡めぐり（1）")）。
