カープが四半世紀ぶりにリーグ優勝して狂喜乱舞した年だわ。
当時の米国大統領が[来広]({{< ref "/remark/2016/05/28-stories.md#hrsm" >}} "Barack Obama 米国大統領の来広")したりもしたな。
「オデッセイ（火星の人）」「シン・ゴジラ」「君の名は。」と（私にしては）やたらと映画を観た年でもあった。
なんでも記事にしておくものである（笑）

この記事を見て真っ先に思い出したのはホルヘ・ルイス・ボルヘスの『砂の本』に収録されている短編「会議」だ。
普通はボルヘスと言えば「バベルの図書館」のほうを連想するかもしれないが（笑）

- [「荒れた農場の掘ったて小屋でがなりたてる、いかさま師の集団」へ]({{< ref "/remark/2017/09/congreso.md" >}})

{{< fig-quote  title="『砂の本』より「会議」" >}}
わしらの企てた計画は、とてつもなく広大なもので、 ――いまのわしにはそれがわかるが―― 全世界を包含するほかないことになる。それは、荒れた農場の掘ったて小屋でがなりたてる、いかさま師の集団じゃない。世界会議は、世界の最初の瞬間と同時にはじまって、わしらが塵に帰ったときもなおつづいてゆくのだ。
{{< /fig-quote >}}

最近 Tim Berners-Lee さん著作の『[THIS IS FOR EVERYONE]』をスキマ時間などでチマチマ読んでいる。

Tim Berners-Lee さんといえば World Wide Web (WWW) の発明者として有名である[^w1]。
その彼による Web 誕生からの回顧録だ。
まだ半分しか読んでないけど。

[^w1]: 『[THIS IS FOR EVERYONE]』の中で World Wide Web なら3音節で発音できるのに，略した WWW は9音節なので，却って長くなるという話に笑ってしまった。

WWW の登場によってインターネットは大きく変わった。
本当の意味でインターネットによってコンピュータの情報資源が「繋がった」と言えるのは WWW 登場以降なのではないだろうか。

WWW は，その黎明期から私企業による囲い込みと独占&排除の対象となっているというのが興味深かった。
それこそ [NCSA Mosaic](https://en.wikipedia.org/wiki/NCSA_Mosaic "NCSA Mosaic - Wikipedia") とか。
これは残りも読了して真面目に感想文とか書いたほうがいいかもしれん。

旧 Twitter が改名とともにメタクソ化し， Mastodon を含む Fediverse エコシステムが再発見され， Bluesky/ATProto などの新興プラットフォームあるいはプロトコルが登場するようになって少し考えが変わったのだが，今考えるべきは「データの永続性」ではなく「データの可搬性」ではないだろうか。
何故なら，ネット上のデータは，[どう見たって儚いだろう](https://dic.nicovideo.jp/a/%E3%81%A9%E3%81%86%E8%A6%8B%E3%81%9F%E3%81%A3%E3%81%A6%E5%84%9A%E3%81%84%E3%81%A0%E3%82%8D%21 "どう見たって儚いだろ!とは (ドウミタッテハカナイダロとは) [単語記事] - ニコニコ大百科")。

{{< fig-quote type="markdown" title="おやすみ、インターネットの時代" link="https://wirelesswire.jp/2026/11/94886/" >}}
この本では、「企業にとって「このデータを保存する価値があるか？」という問いは、本質的に「このデータが、直接的あるいは間接的に、収益に貢献するだろうか？」という問いに等しい」（p.165）、「明確に資本へと翻訳できない価値は、完全に無関係なものとなる。美、人間としての繁栄、伝統、そして後で詳しく述べるように、死者への敬意は、収益性がある場合にのみ価値がある」（p.187）というシビアな認識が示されていますが、ブログサービスやSNSサービスが故人のデータを残しているのは、飽くまでそれに収益の可能性が残っているからに過ぎません。
{{< /fig-quote >}}

たとえば，作家の結城浩さんは日頃の活動を，個人サイトやメールマガジン，あるいは各種 SNS などに広く発信されている。
それを AI 等のツールを駆使して無理なく日常のルーチンに組み込んでおられるのは本当に凄いと思う。

自分自身を偏在させるのはネット上での生存戦略のひとつとしてアリだと思う。
かつての P2P ファイル共有の意義はまさにそれだった。
なんとなく押井守版の「[GHOST IN THE SHELL](https://link.amazon/A05b9XY8y)」を[連想]({{< ref "/remark/2017/10/too-many-ghosts.md" >}} "今こそ「グリゴリの捕縛」を読め！ または遍在する草薙素子")してしまうが（笑）

記憶というのは特定のメモリやストレージに情報を固定することではなく，人と人の間で連綿と受け継がれる動的な営みである。
「私」という生物的主観が消失したあともネット上を生き延びたいなら（あるいは他者から「生き延びて欲しい」と乞われるなら），近代が規定する「個人」をアップデートする必要があるのかもしれない。

「ネットはネタでメタ」だった時代はとうの昔に終わった。
私たちは「つながりっぱなしの日常」を生きている。
[インターネットから切り離されたインターネットはありますか](https://goark.fedicity.net/@spiegel/117527199246307947)ねぇ。
まぁ，上手くいかないものをリセットしてやり直そうというのは中二病的発想ではあるか（笑）
